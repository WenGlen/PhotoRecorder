# 阿美中會工地記錄平台：示範網站

https://wenglen.github.io/PhotoRecorder/

正式版程式的示範模式（假資料、可以切換身分），不接 API、不會動到正式的資料。
從 `glen-wen/PhotoRecorder-code` 用 `npm run build:demo` 打包（`dist-demo` 裡的檔案原樣放在這裡），GitHub Pages 用 main 分支的根目錄。

- 舊的 Demo（v42，一頁式的原型）在 tag `v42`。
- 直接打開內頁網址、重新整理：GitHub Pages 會回 `404.html`（跟 `index.html` 一樣），畫面照常開起來。
